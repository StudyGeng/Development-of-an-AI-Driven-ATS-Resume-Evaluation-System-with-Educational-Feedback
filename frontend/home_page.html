Write with evidence

A stronger bullet starts with what you did.

The goal is clear, truthful detail a reader can understand. This fictional example shows how specificity helps.

Before · vague

“Responsible for developing a web application.”

After · specific

“Built a Flask web application with PostgreSQL and three API endpoints for campus timetable search.”

✦ Write only what you actually did. Use tools, actions, and outcomes you can support.

Privacy Policy

Data use for UTS CS Career Navigator

We use account details and resume content to provide this educational tool.

Uploaded resumes are processed to generate ATS feedback, keyword matching, and improvement suggestions.

Your account stores your name, email, and a password hash. Saved analysis records can include text extracted from your resume.

Do not upload confidential or third-party information without permission. This tool is for educational feedback, so review its suggestions before using them in an application.

Research Credits

Methods used in the project

The app uses PDF extraction, optional image OCR, TF-IDF similarity scoring, and simple rule-based feedback generation.

The layout and workflows were shaped to support resume preparation for UTS Computer Science students.

About This Project

Built for students learning to improve a resume

This educational project was developed at the University of Technology Sarawak (UTS), Malaysia.

It offers guidance for resume preparation. It is not an official university service or an employer's hiring system.
